# ShopInbox

Web app inbox đa kênh cho cửa hàng: gom tin nhắn, trả lời, lưu đơn hàng.

Bản hiện tại là **Lát 1** — khung đăng nhập, menu, inbox 3 cột, dữ liệu mẫu. Chưa kết nối Facebook / Zalo / Instagram thật.

## Chạy local

```bash
npm install
npm run dev
```

Mở [http://localhost:3000](http://localhost:3000), bấm **Vào cửa hàng demo**.
